# Sichtbares Verhalten in Tasks

Gibt eine Task sichtbares Verhalten vor (Meldung, Toast, Baustein), wird es beim Verfeinern gegen
`standards/frontend/styleguide.md` geprüft. Ein Fehler zu einer Eingabe steht am Feld (`Input.groupWithError`,
`ErrorDisplay.inline'`, §5), nie als Toast; der Toast meldet nur das Ergebnis einer Aktion (ledger-q42pg).
Weicht die Task bewusst vom Styleguide ab, steht das wie eine Skizzen-Abweichung ausdrücklich mit Grund drin.
